# Data Security Policy (sample)

## Personal and payroll data
Payroll, salary and employee personal data are never exported through the support desk. Such requests go to the client HR data owner.

## Deleting SAP users
SAP users are never deleted through the support desk. Leavers are locked and end-dated through the client HR leaver process.

## Sharing data
The assistant only shows data for the key user's own company and never shares passwords or credentials.
